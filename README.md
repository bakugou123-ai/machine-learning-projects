# Machine Learning Projects

A portfolio of applied machine learning projects spanning classification, computer vision, and
NLP — covering the full workflow from EDA and feature engineering through model tuning and
evaluation.

## Projects

| Project | Domain | Summary |
|---|---|---|
| [Employee Churn Prediction](./employee-churn-predictive-analysis.md) | Classification / HR analytics | Predicts employee attrition from HR data; tuned Decision Tree reached ~0.975 ROC-AUC, with `satisfaction_level` as the dominant predictor. |
| [Plant Disease Detection](./plant-disease-detection.md) | Computer vision (CNN) | Custom CNN classifies plant leaf images into 39 disease/healthy categories from the PlantVillage dataset. |
| [TikTok Claims vs. Opinions Classification](./tiktok-claims-classification.md) | NLP / content moderation | Classifies reported videos as factual claims vs. opinions to help prioritize moderator review; tuned Random Forest reached ~99% test accuracy. |

## Skills Demonstrated

- **EDA & statistics:** data cleaning, outlier detection, multicollinearity (VIF) checks,
  hypothesis testing
- **Feature engineering:** categorical encoding, bag-of-words text vectorization, combining
  text and numeric features
- **Modeling:** Logistic Regression, Decision Trees, Random Forest, XGBoost, and CNNs (Keras/TensorFlow)
- **Model selection & tuning:** `GridSearchCV` cross-validation, ROC-AUC/precision/recall
  trade-off analysis, feature importance interpretation
